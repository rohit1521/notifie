Notifie is an event-driven workflow runtime for mobile push notifications. Add the SDK to an
existing app, track the events your product understands, and configure delivery in the dashboard.

## What Notifie handles

- Durable event ingestion with retry-safe message IDs
- Anonymous device identity and mobile push-token registration
- APNs and FCM provider delivery
- Event, schedule, recurring, inactivity, and API-triggered automations
- A visual dashboard for events, users, audiences, flows, and delivery status

Notifie currently delivers **mobile push notifications**. The Web SDK tracks events but does
not register browser push subscriptions.
