<Note>
  The CLI is published on npm as `@notifie-dev/cli`. The current public beta is
  `0.1.0-beta.3`.
</Note>

Run without installing:

```bash
npx @notifie-dev/cli@beta --help
```

Or install the beta globally:

```bash
npm install --global @notifie-dev/cli@beta
notifie --help
```

## Initialize a project

<Warning>
  `notifie init` writes the complete ingest key to `notifie.json`. Add `notifie.json` to your
  app's `.gitignore` before running the command and never commit that file.
</Warning>

```bash
echo "notifie.json" >> .gitignore
export NOTIFIE_URL='https://notifie.dev'
notifie init <SDK_INGEST_KEY>
notifie init <SDK_INGEST_KEY> --yes
```

Run the command from an existing iOS, Android, Flutter, React Native, Expo, or web app root. It
writes `notifie.json`, detects the project, plans safe file changes, and prints remaining manual
provider steps.

Environment variables override the file:

```bash
export NOTIFIE_API_KEY='<SDK_INGEST_KEY>'
export NOTIFIE_URL='https://notifie.dev'
```

## Commands

```text
notifie init <key> [--yes]
notifie doctor
notifie templates
notifie install <template-id>
notifie test-push
```

`notifie install` describes the selected template and sends you to the dashboard to confirm event
binding. It does not silently install an automation from a mobile ingest key.
