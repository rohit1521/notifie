## Requirements

- iOS 15+ or macOS 12+
- Swift 5.9+

macOS supports events and identification. Notification permission and APNs token enrollment in the
current SDK require UIKit and are available only on iOS.

## Install

Swift Package Manager:

```swift
.package(
    url: "https://github.com/rohit1521/notifie",
    exact: "0.1.0-beta.4"
)
```

CocoaPods is published, which is also what lets the Flutter plugin depend on
this SDK:

```ruby
pod 'Notifie', '0.1.0-beta.4'
```

## Initialize and track

```swift
import Notifie

Notifie.initialize(
    apiKey: "<SDK_INGEST_KEY>"
)

Notifie.identify("user-123", properties: [
    "plan": .string("pro")
])

Notifie.track("purchase_completed", properties: [
    "amount": .double(9.99)
])
```

## Enable notifications

Request permission when it makes sense in your product:

```swift
let result = await Notifie.enableNotifications()
```

Apple returns APNs registration through `UIApplicationDelegate`. Forward both
callbacks so `enableNotifications()` can finish immediately:

```swift
func application(
    _ application: UIApplication,
    didRegisterForRemoteNotificationsWithDeviceToken token: Data
) {
    Notifie.didRegisterForRemoteNotifications(deviceToken: token)
}

func application(
    _ application: UIApplication,
    didFailToRegisterForRemoteNotificationsWithError error: Error
) {
    Notifie.didFailToRegisterForRemoteNotifications(error: error)
}
```

Without these callbacks, `enableNotifications()` waits ten seconds and returns
`.noToken` even when permission and the Push Notifications capability are
correct.

To record foreground receipt and notification-open attribution, make
`AppDelegate` conform to `UNUserNotificationCenterDelegate`, set the delegate
during launch, and forward both events:

```swift
UNUserNotificationCenter.current().delegate = self

func userNotificationCenter(
    _ center: UNUserNotificationCenter,
    willPresent notification: UNNotification
) async -> UNNotificationPresentationOptions {
    Notifie.notificationReceived(
        userInfo: notification.request.content.userInfo
    )
    return [.banner, .sound]
}

func userNotificationCenter(
    _ center: UNUserNotificationCenter,
    didReceive response: UNNotificationResponse
) async {
    Notifie.notificationOpened(response: response)
}
```

Continue with [iOS push setup](/ios-push-setup).

## Session helpers

```swift
await Notifie.flush()
Notifie.reset()
```

`reset()` clears the identified user and creates a new anonymous identity for logout.
