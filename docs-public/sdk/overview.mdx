description: "Choose the Notifie SDK that matches your application stack."
---

| Platform | Events | Push registration | Identify API | Distribution |
| --- | --- | --- | --- | --- |
| Swift | Yes | APNs | Yes | CocoaPods |
| Android | Yes | FCM | Yes | Maven Central |
| Flutter | Yes | APNs / FCM | Yes | pub.dev |
| React Native | Yes | FCM | Not yet on main | Source only — not published |
| Server | Yes | No | Yes | Source only — not published |
| Web | Yes | No | Not yet | Source only — not published |

<Note>
  Published today: `Notifie 0.1.0-beta.3` on CocoaPods,
  `dev.notifie:notifie-android:0.1.0-beta.4` on Maven Central, and
  `notifie_flutter 0.1.0-beta.7` on pub.dev.

  React Native, Server and Web are **not on any registry**. Installing them by
  name will fail; build them from a checkout of the public repository until
  their registry releases are available.
</Note>

All SDKs must use the hosted base URL in production:

```text
https://notifie.dev
```
