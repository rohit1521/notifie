---
title: "SDK overview"
description: "Choose the Notifie SDK that matches your application stack."
---

| Platform | Events | Push registration | Identify API | Distribution |
| --- | --- | --- | --- | --- |
| Swift | Yes | APNs | Yes | CocoaPods / repository package |
| Android | Yes | FCM | Yes | Maven Central / repository module |
| Flutter | Yes | APNs / FCM | Yes | pub.dev / repository path package |
| React Native | Yes | FCM | Not yet on main | Repository workspace package |
| Server | Yes | No | Yes | Repository workspace package |
| Web | Yes | No | Not yet | Repository workspace package |

<Note>
  The Swift SDK is published to CocoaPods as `Notifie 0.1.0-beta.2`, and the
  Android SDK is on Maven Central as
  `dev.notifie:notifie-android:0.1.0-beta.3`, and Flutter is on pub.dev as
  `notifie_flutter 0.1.0-beta.3`. React Native, Server and Web remain
  early-access packages distributed from the public Notifie repository until
  their registry releases are available.
</Note>

All SDKs must use the hosted base URL in production:

```text
https://notifie.dev
```
